# Hostel Management System - PUST

A web application designed to manage hostel operations, student applications, and administrative workflows for Pabna University of Science and Technology (PUST).

## Features

- **Student Portal:** Apply for seats, submit applications, and track application status.
- **Admin Dashboard:** Manage student records, approve/reject seat applications, and organize room allocations.
- **User Authentication:** Secure login and registration for students and administrators.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (or React / Vue if applicable)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
